# Быстрее сделать самому

Презентация Андрея Смирнова для онлайн-курса Стратоплана, ноябрь 2026.

[Открыть презентацию](https://sandark7.github.io/BCM26/)

70 слайдов с планом на 40 минут о том, как договориться о результате и самостоятельности, выбрать раннюю точку проверки и принять работу, сохраняя исполнение у команды. Сквозной пример — подпроект распознавания фотографий приёмки.

Нажми на слайд, чтобы начать показ. Стрелка вправо или пробел открывает следующий шаг, стрелка влево возвращает назад, Esc открывает обзор.

Статическая HTML-презентация на Shower. Использует три исходных шаблона из моих предыдущих докладов: фраза по центру, заголовок со списком и заголовок с картинкой. Картинки, шрифты и движок находятся в репозитории, для локального показа достаточно открыть `index.html`.

Источники темы и визуальных материалов указаны в [UPSTREAM.json](UPSTREAM.json). Лицензии Shower и шрифтов сохранены в каталоге `shower`.
